# Gabio Legacy Group — V3

Premium multilingual corporate holding website for Gabio Legacy Group.

## Languages
- Français
- English
- Español

## Main assets
- `assets/logos/` — transparent, visibility-optimized brand logos
- `assets/images/` — generated editorial illustrations for Kinshasa, corporate, Creamy Mustache, Infinity Dreams and investment sections

## Structure
- `index.html` — main holding website
- `companies/creamy-mustache.html` — portfolio company page
- `companies/infinity-dreams.html` — portfolio company page
- `style.css` — main visual system
- `company.css` — company-page styling
- `script.js` — navigation, language switcher and reveal animations
